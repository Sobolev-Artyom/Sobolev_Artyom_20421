# Инструкция по запуску

### 1. Скачать файлы cVAE.py и requirements.txt, добавив их в одну директорию.
### 2. Проверить установленную версию Python (если Python нет, то установить). Должен быть Python 3.13.
### 3. После выполнения шагов 1 и 2, выполнить команду:
```bash
pip install -r requirements.txt
```
### 4. Перед запуском программы, проверить значение 'seed' (44 строка кода). Оно должно быть равно 15 для схожих результатов.
### 5. Проверить значения параметров для экспериментов (их всего три). Параметры указаны на рисунке.
### 6. Для запуска программы нужно прописать команду:
```bash
python cVAE.py
```
### Или запустить программу явно (если среда программирования позволяет это сделать).
## Внимание!! 
### Во время работы программы будут созданы дополнительные директории: results, logs и data. В первой будут храниться сгенерированные изображения для каждого числа эммбеддингов, классовое сравнение изображений (Реальные изображения из набора, сгенерированные сетью), матрицы замешательства, графики латентного(скрытого) пространства и графики прогресса обучения.
### Во второй директории будут храниться логи всего процесса обучения. 
### В третьей директории будут находиться данные загруженного во время работы программы набора Fashion-Mnist.
